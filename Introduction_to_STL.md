# 📚 Introduction to Standard Template Library (STL)

## 📖 What is STL?

The **Standard Template Library (STL)** is a powerful library in C++ that provides a collection of pre-built classes and functions for common data structures and algorithms. It helps developers write efficient, reusable, and optimized code without implementing everything from scratch.

STL is a core part of the C++ Standard Library and is widely used in competitive programming, technical interviews, and software development.

---

# 🚀 Why Use STL?

- ✅ Reduces code complexity
- ✅ Saves development time
- ✅ Provides optimized implementations
- ✅ Increases code readability
- ✅ Improves performance
- ✅ Widely used in coding interviews and competitive programming

---

# 🏗️ Components of STL

The Standard Template Library consists of four main components:

## 1. Containers
Containers are data structures used to store and organize data efficiently.

Examples:
- Vector
- Array
- List
- Deque
- Stack
- Queue
- Priority Queue
- Set
- Map
- Unordered Set
- Unordered Map

---

## 2. Iterators
Iterators are objects used to traverse elements stored in containers.

Common Iterators:
- `begin()`
- `end()`
- `rbegin()`
- `rend()`

---

## 3. Algorithms
Algorithms are predefined functions that perform operations on data.

Common Algorithms:
- `sort()`
- `reverse()`
- `find()`
- `count()`
- `binary_search()`
- `lower_bound()`
- `upper_bound()`
- `max_element()`
- `min_element()`
- `next_permutation()`

---

## 4. Function Objects (Functors)
Functors are objects that can be called like functions and are often used to customize the behavior of STL algorithms.

Example:
```cpp
sort(v.begin(), v.end(), greater<int>());
```
